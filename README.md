# Korea Prospect Agent MVP

해외 B2B SaaS/AI 회사를 찾아 **한국 진출 타이밍 + 공개 근거 + 담당자 후보 + 한국 잠재고객 샘플 + 아웃바운드 메시지**를 만드는 내부 영업 리서치 도구입니다.

## 핵심 산출물

- 지금 연락할 해외 B2B SaaS 후보
- 왜 지금 연락해야 하는지 공개 근거
- 한국 현지 영업조직 공백 여부
- 공개적으로 확인된 담당자 이메일/직책
- 한국 잠재고객 샘플
- 한국어/영어 아웃바운드 메시지

**개인 이름·이메일은 추측하지 않습니다.** 이메일이나 샘플이 덜 완성돼도 검증된 회사와 근거 자체를 버리지 않고 화면에 남깁니다.

## 담당자 탐색

담당자 이메일은 아래 순서로 찾습니다.

`공식 웹사이트 공개 이메일 → Prospeo → Apollo → Tomba`

- 공식 웹사이트 단계는 별도 키 없이 먼저 실행합니다.
- 각 외부 공급자는 키가 설정된 경우에만 실행합니다.
- 앞 단계에서 결과가 나오면 뒤 공급자는 호출하지 않습니다.
- 성공 결과는 서버 인스턴스에서 12시간, 실패 결과는 20분 캐시해 반복 호출을 줄입니다.
- 추측 이메일은 만들지 않습니다.

선택 환경 변수:

```text
PROSPEO_API_KEY=
APOLLO_API_KEY=
TOMBA_API_KEY=
TOMBA_API_SECRET=
```

## 결과가 덜 완성됐을 때

전체 결과를 숨기지 않습니다.

- 이메일 + 한국 샘플 완료 → **발송 준비**
- 이메일 있음 + 샘플 실패 → **샘플 미완성**으로 후보/메일 유지
- 회사 검증 완료 + 이메일 없음 → **연락처 미확보**로 회사/근거/추천 직책 유지
- 검증 회사 자체가 0개 → 오류 이유를 화면에 표시하고 다음 실행에서 다른 탐색군 사용

## Vercel 환경 변수

필수:

```text
OPENCODE_ZEN_API_KEY=
TAVILY_API_KEY=
```

연락처 공급자 키는 위의 선택 환경 변수 중 필요한 것만 추가합니다.

## 로컬 실행

```powershell
npm i -g vercel
vercel login
vercel dev
```

처음에는 잠재고객 5~8개 정도로 품질을 확인하세요.
