# Korea Prospect Agent MVP

해외 B2B·Web3 회사를 찾아 **한국 방문·행사 근거 + 담당자 이메일 + 아웃바운드 메시지**를 만드는 내부 영업 리서치 도구입니다.

## KBW 후보 기준

KBW 캠페인은 회사별 공개 근거를 도메인 기준으로 합친 뒤 등급을 부여합니다.

- **A**: 주최·공동주최·스폰서·부스·사이드 이벤트 근거
- **B**: 회사나 팀의 공식 KBW·서울 참석 발표
- **C**: 개별 연사만 확인
- **D**: 투자·TGE·한국 관심 신호만 확인

이메일 탐색은 **A·B 회사에만** 실행합니다. C·D는 이메일 API 비용을 쓰지 않습니다.

## 중복 제외

- 한 번 화면에 노출된 회사 도메인은 브라우저의 누적 노출 이력에 저장해 다음 검색 전에 제외합니다.
- 사용자가 직접 제외한 도메인과 현재 화면의 회사도 검색 전에 제외합니다.
- Gmail로 실제 발송한 회사는 Supabase 발송 DB에서 읽어 서버와 화면 양쪽에서 검색 전에 제외합니다.
- 회사명 대신 정규화된 루트 도메인을 중복 기준으로 사용합니다.

## 담당자 탐색

담당자 이메일은 여러 경로에서 수집하고, 같은 이메일의 근거를 합쳐 점수화합니다.

`공식 웹사이트 + Jina Reader → Hunter Domain Search·Verifier → Prospeo → Apollo → Tomba`

- 공식 홈페이지의 Contact·About·Team·Leadership·Partnerships·Events 페이지를 확인합니다.
- Jina는 동적이거나 읽기 어려운 공식 페이지를 텍스트로 변환해 공개 이메일을 보강합니다.
- Hunter는 도메인 이메일 수집과 최종 유효성 검증에 사용합니다.
- Prospeo·Apollo·Tomba는 설정된 경우 직무가 맞는 개인 담당자를 추가 탐색합니다.
- 공급자 한 곳에서 일반 대표메일만 발견해도 탐색을 종료하지 않습니다.
- 추측 이메일은 생성하지 않습니다.

### 이메일 점수

- 유효성 최대 30점
- 직무 일치 최대 30점
- 개인 또는 역할 이메일 최대 20점
- 회사 도메인 일치 10점
- 복수 출처·공급자 근거 최대 10점
- 지원·대표메일, accept-all, 직무 불일치는 감점

**75점 이상인 개인 담당자 또는 역할 대표메일**을 확보해야 발송 가능으로 처리합니다. 우선순위는 개인 담당자 → `events@`·`partnerships@` 등 역할 메일 → 일반 대표메일입니다.

성공 결과는 서버 인스턴스에서 12시간, 미확보 결과는 2분 캐시합니다. 공급자 연결 상태가 바뀌면 기존 실패 캐시를 재사용하지 않습니다.

## 환경 변수

필수 검색·페이지 분석:

```text
TAVILY_API_KEY=
JINA_API_KEY=
```

메일 검색·검증:

```text
HUNTER_API_KEY=
```

선택 연락처 공급자:

```text
PROSPEO_API_KEY=
APOLLO_API_KEY=
TOMBA_API_KEY=
TOMBA_API_SECRET=
```

발송 이력 중복 제외에는 `GMAIL_SESSION_SECRET`과 기존 Gmail·Supabase 구성이 사용됩니다.
